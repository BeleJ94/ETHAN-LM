Avant de commencer

Les codes couleur de la fiche

Cellules jaunes : zones à remplir En-tête rouge (*) : colonne obligatoire En-tête bleu : colonne facultative Ligne grise en italique : exemple

Règles générales

  • Une ligne par élément, à partir de la ligne qui suit l'exemple, sans ligne vide au milieu.
  • Ne modifiez ni ne supprimez la ligne d'exemple (grise) : elle est ignorée à l'import.
  • Ne renommez pas les onglets et ne changez pas l'ordre des colonnes : l'import les reconnaît par leur numéro (« 2. Sites », « 3. Entrepôts »…).
  • Les codes laissés vides sont générés automatiquement (SITE-01, CLI-0001, FRS-0001, REA-0001…). Ne les inventez que si vous avez déjà une codification interne.
  • Les liens entre onglets se font par le nom (ou le code), écrit à l'identique : un entrepôt cite le nom exact de son site, un article le code de sa famille, un lieu de livraison le nom exact de son client.
  • Listes déroulantes (devises, couleurs, Oui/Non, Fourni par, Niveau, Mode, Transport, Blocage) : choisissez toujours une valeur de la liste, ne tapez pas de texte libre.
  • Dates au format JJ/MM/AAAA ; nombres sans unité ni symbole monétaire (la virgule ou le point décimal sont acceptés).
  • Adresses e-mail : une seule adresse valide par cellule.

Les listes de référence (onglet « Listes ») Cet onglet alimente les listes déroulantes. N'y touchez pas. Valeurs disponibles :
  • Devises : USD, EUR, CDF, CNY, ZAR, AED (+ celles ajoutées dans l'onglet 4)
  • Couleurs : blue, green, orange, red, purple, teal (gray par défaut)
  • Fourni par : Fournisseur · Transitaire / agence en douane · Douane · Client · Interne
  • Niveau : Dossier (une fois par commande) · Expédition (à chaque livraison)
  • Mode d'exécution : Tous · Achat local · Importation · Vente sur stock
  • Transport : Tous · Route · Rail · Mer · Air · Multimodal
  • Bloque à l'étape : Aucun · Départ · Réception · Facturation · Clôture

Deux façons d’encoder
  • En masse (mise en service, grandes listes) : remplir la fiche Excel puis Administration › Import des référentiels.
  • Au fil de l’eau (un nouveau client, un article de plus) : directement dans l’écran indiqué par l’encadré 📍 Où le trouver de chaque chapitre.
Repères d’écranSur chaque liste, le bouton bleu + Nouveau… est en haut à droite ; le crayon d’une ligne ouvre la modification ; le nom d’un client ou d’une banque ouvre sa fiche, où se gèrent ses lieux de livraison ou ses agences.

Importer le fichier rempli

  1. Connectez-vous avec un compte administrateur, dépliez la section Administration de la barre latérale et cliquez sur Import des référentiels. Le bouton Fiche de collecte vierge (en haut à droite) télécharge le classeur vide.
  2. Choisissez le mode :
    • Mettre à jour (habituel) : les éléments déjà présents (même code ou même nom) sont mis à jour avec les cellules remplies — une cellule vide ne remplace rien — et les nouveaux sont créés. Rien n'est supprimé.
    • Réinitialiser (mise en service uniquement) : efface les opérations et les référentiels, puis importe le fichier. Les comptes utilisateurs, les sites et la configuration sont conservés. Confirmation par la saisie de REINITIALISER.
  3. Déposez le fichier puis cliquez sur Analyser le fichier : une simulation s'affiche, sans rien enregistrer — éléments à créer, à mettre à jour, inchangés, et la liste des erreurs avec onglet et n° de ligne.
  4. Corrigez les erreurs dans Excel, redéposez le fichier, puis cliquez sur Confirmer l'import.
Tout ou rienUne seule erreur bloque tout l'import : la base n'est jamais à moitié remplie. Le même fichier peut être réimporté autant de fois que nécessaire sans créer de doublons.
